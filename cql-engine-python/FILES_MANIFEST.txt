DESIGN HIGHLIGHTS
=================

1. Dataclass Usage
   - Quantity, Ratio, Code, Vocabulary, Concept, ValueSet, Tuple use @dataclass
   - Reduces boilerplate, improves readability
   - Automatic __init__, __repr__, __eq__, __hash__

2. Type Hints
   - Full type hints on all functions
   - Union types (int | str | date)
   - Optional[T] for nullable values
   - Generic types (Iterator[T], List[T])

3. Modern Python Features
   - Match statements for precision handling (Date, DateTime, Time __str__)
   - __slots__ for memory efficiency (BaseTemporal derivatives)
   - Protocol for CqlType interface
   - dataclasses for value objects

4. Flexible Constructors
   - Multiple overloads via type checking in __init__
   - Date(2021), Date("2021-05-15"), Date(py_date(...))
   - DateTime and Time similarly flexible

5. Operator Overloading
   - __lt__, __le__, __gt__, __ge__, __eq__, __hash__
   - Makes temporal and numeric types naturally comparable
   - Supports sorting and set operations

6. Method Chaining
   - with_*() methods return self for chaining
   - Example: quantity.with_value(100).with_unit("mg")

7. Python Naming Conventions
   - snake_case for methods: get_date(), set_precision()
   - Direct attribute access where appropriate
   - _private for internal implementation

# Temporal types
from cql_engine.runtime import Date, DateTime, Time, Precision

d = Date(2021, 5, 15)

# Quantities
from cql_engine.runtime import Quantity

concept = Concept().with_code(code)
cs = CodeSystem().with_id("cs-id").with_version("1.0")
vs = ValueSet().with_id("vs-id").with_code_system(cs)

# Collections
from cql_engine.runtime import Interval, Tuple

interval = Interval(1, True, 10, True)  # [1, 10]
t = Tuple()
